## About Me

I'm a Machine Learning Engineer focused on **Computer Vision and production-ready ML systems**.

I work across the full ML lifecycle:

- data preparation and analysis
- model training and evaluation
- object detection and image classification
- model optimization and inference
- backend API development
- containerized deployment
- ML infrastructure and monitoring

I build ML systems using **PyTorch, TensorFlow, OpenCV, Transformers, FastAPI, Docker, Kubernetes and MLflow**.

I also work with **classical ML, gradient boosting, LLM/RAG pipelines, multimodal models, recommendation systems and tabular data**.
